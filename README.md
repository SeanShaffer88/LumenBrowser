# LumenBrowser
Planned Windows browser project based on Firefox, with work proposed in a separate development branch.

**Status: foundation work in review.** The default branch currently contains project documentation and licensing, not a buildable browser. No LumenBrowser release is available here.

Implementation and its build instructions are proposed in [PR #1](https://github.com/SeanShaffer88/LumenBrowser/pull/1). Read that PR for the scope and validation of the proposed work; an open PR is not a merged or released capability.

Firefox is an upstream project with its own code, trademarks, and licenses. This repository's license does not replace the terms of upstream components. Browser runtime, installer, update, and compatibility acceptance remain prerequisites for any future release.
