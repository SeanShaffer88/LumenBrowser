The pinned Glean preferences documentation describes collection-independent ping exceptions and deletion requests when collection is disabled. Therefore, a false upload master preference must not be described as the complete absence of local metrics, identifiers, SDK activity or every possible request. The unofficial-build transport layer adds suppression with explicit debug/local test exceptions; it does not remove the SDK. DAP is a separate transport surface.
